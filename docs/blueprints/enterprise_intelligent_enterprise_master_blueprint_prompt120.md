## ETAPA 8 — ARQUITETURA DE APLICAÇÕES (ENTERPRISE APPLICATION ARCHITECTURE — C4 MODEL)

* **C4 Model — 4 Níveis de Detalhe Arquitetural:**
  * **Context (L1):** Legis Connect SaaS Platform ↔ Usuários (Web/Mobile) ↔ Parceiros (API) ↔ Sistemas Externos (DataJud/Stripe/Salesforce).
  * **Container (L2):** Next.js Frontend → NestJS API Gateway → 12 Microservices (NestJS) → Kafka MSK → PostgreSQL RDS / Redis / S3 Lakehouse.
  * **Component (L3):** Cada microserviço decomposto em Controllers, Services, Repositories, Domain Events, Adapters.
  * **Code (L4):** Padrões de código TypeScript (ESLint + Prettier), Clean Architecture por módulo NestJS, testes unitários >= 80% coverage.
