```
ECOSYSTEM VALUE GROWTH MODEL (Metcalfe's Law):

V(t) = α × N(t)² + β × D(t) × Q(t)

Onde:
 V(t) = Valor total do ecossistema no tempo t
 N(t) = Número de participantes ativos (all types)
 D(t) = Volume de dados do ecossistema (TB)
 Q(t) = Qualidade média dos matches (0.0–1.0)
 α    = Coeficiente de efeito de rede (0.0042, calibrado)
 β    = Coeficiente de data network effect (12.4)

PROJEÇÕES:
 2026 (N=12.000, D=85TB, Q=0.87): V = R$ 820M de valor de ecossistema
```
