## ETAPA 8 — SUSTAINABLE SOFTWARE ENGINEERING (GREEN SOFTWARE FRAMEWORK)

### 8.1 Engenharia de Software Sustentável (Green Software Foundation)

```
SOFTWARE CARBON INTENSITY (SCI) FORMULA & REDUCTION:

SCI = ((E * I) + M) / R

Onde:
  E = Energia consumida pela execução do software (kWh)
  I = Intensidade de carbono da matriz energética (gCO2e/kWh)
  M = Carbono incorporado ao hardware (gCO2e)
  R = Unidade de funcionalidade (Ex: 1 requisição de análise contratual)

MÉTRICA LEGIS CONNECT:
  • AS-IS:  SCI = 4.8 gCO2e / requisição
  • TO-BE:  SCI = 0.65 gCO2e / requisição (Redução de 86.4% via otimização de código e cache)
```
