TIPOS DE EXPERIMENTOS:
  1. A/B Test: Comparação de 2 variantes em usuários divididos aleatoriamente
  2. Multivariate Test: Comparação de múltiplas variantes simultâneas
  3. Feature Flag Rollout: Rollout gradual 1% → 10% → 50% → 100%
  4. Holdout Group: Grupo de controle permanente para comparar efeito global
  5. AI Experiment: Comparação de modelos de IA (ex: gpt-4o vs. claude-sonnet)

CRITÉRIOS DE EXECUÇÃO (Statistical Rigor):
  Significance Level: α = 0.05 (95% de confiança)
  Power: β = 0.80 (80% de poder estatístico para detectar efeito real)
  Minimum Detectable Effect (MDE): definido antes do experimento
  Minimum Sample Size: calculado com calculadora de power (automatizado)
  No peeking rule: sem olhar resultados antes do tamanho amostral atingido
  Duration: mínimo 7 dias (captura variação semanal de comportamento)

PROCESSO DE EXPERIMENTO:
  1. Hipótese: "Se fizermos X, esperamos Y no outcome Z (magnitude MDE)"
  2. Design: Definir variantes + métricas primárias + métricas de guardrail
  3. Execução: Launch via GrowthBook + monitoramento automático
  4. Análise: Sequential testing + confidence intervals + practical significance
  5. Decisão: Ship / Iterate / Kill + registro na Product Knowledge Base
  6. Aprendizado: Insight documentado no Dovetail + OST atualizado

EXPERIMENT VELOCITY TARGET:
  2026: 2 experimentos por squad por mês
